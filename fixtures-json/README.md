# Normalized fixtures

Generated by `cargo run --locked --release -p fixture-json`. Snapshot generation
reads metadata from these JSON files and source text from the original
`fixtures/` directory. JSON files do not embed source text.
All paths identify upstream fixtures or virtual files, independent of the local
checkout location. Fixtures retain positive and negative cases; consumers choose
which cases and diagnostics they support.

- `test262/**/*.js.json`: source path relative to `fixtures/test262/test`,
  metadata (`flags`, `features`, `includes`, negative phase/type), and available
  `sloppy`/`strict`/`module` modes. Strict mode adds `"use strict";\n` before
  the original source. `_FIXTURE` files remain available and can be excluded by
  consumers.
- `typescript/{compiler,conformance}/**/*.json`: ordered virtual files, a
  separate tsconfig file, symlinks, current directory, original options, and
  configuration variants. Each virtual file stores its name and zero-based
  source line indices. Decode the physical test file (including BOM handling),
  normalize CRLF to LF, then join the indexed lines with LF to restore its content.
  An empty index list restores an empty file. Each variant stores its baseline
  name, expanded options, and per-file diagnostic codes. Duplicate baseline file sections are
  separate ordered entries; a null file identifies project-wide diagnostics.
  Files excluded by the pinned tsrs harness retain their source references but
  have no runnable variants.
- `typescript/libraries.json`: supporting library names relative to
  `fixtures/typescript/tsc/testdata/tests/lib`.
- `typescript/syntax-codes.json`: syntax/grammar diagnostic codes from the pinned
  TypeScript fixture sources.
- `swc-minifier/**/*.json`: minifier issue inputs and resolver parser settings.

TypeScript decoding and virtual-file splitting follow the pinned tsrs harness.
Input content and virtual-file order are preserved; diagnostic message text is
omitted. Regenerate this directory after changing fixture revisions or decoding.
